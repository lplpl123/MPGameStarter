## MPGamerStarter

A lightweight game launcher that keeps your playtime in check and your game library organized — no more guessing how long you've played or where that game went.

### Features

- **Playtime Tracking** — Automatically records play sessions and keeps a running log of time spent per game.
- **Game Library Management** — Add, organize, and manage your games in one place.

### Why MPGamerStarter?

- Know exactly how much time you spend gaming
- Keep every game organized and easy to find
- Simple, focused, and lightweight
